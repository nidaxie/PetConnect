Şimdi sistemi SQLite yerine PostgreSQL’e tamamen taşımanı istiyorum.

Amaç:
Gerçek production mantığına daha yakın, PostgreSQL kullanan tam dinamik bir sistem oluşturmak.

Yapılacaklar:

1. SQLite bağımlılıklarını tamamen kaldır

* sqlite3 paketlerini kaldır
* sqlite database dosyalarını kaldır
* tüm sqlite bağlantı kodlarını sil

2. PostgreSQL kurulumu için yapı oluştur
   Backend tarafında:

* pg package kullan
* dotenv kullan
* database connection ayrı bir config dosyasında olsun

Örnek yapı:
backend/
├── config/
│    └── db.js
├── routes/
├── controllers/
├── models/
├── middleware/
├── server.js
└── .env

3. .env desteği ekle
   Aşağıdaki environment değişkenlerini kullan:

PORT=5000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=petconnect
DB_USER=postgres
DB_PASSWORD=yourpassword

JWT_SECRET=supersecretkey

4. PostgreSQL connection pool oluştur
   pg Pool kullan.
   Sunucu açılırken DB bağlantısı test edilsin.

5. Tüm tablolar PostgreSQL uyumlu hale getirilsin
   SQLite syntaxlarını PostgreSQL syntaxına çevir.

Özellikle:

* INTEGER PRIMARY KEY AUTOINCREMENT yerine SERIAL
* TEXT yerine uygun yerlerde VARCHAR
* BOOLEAN kullan
* TIMESTAMP DEFAULT CURRENT_TIMESTAMP kullan
* UUID destekli yapı kur

6. UUID sistemi ekle
   users, shelters, pets tablolarında UUID kullan.
   uuid extension ve uuid_generate_v4() kullan.

7. PostgreSQL için tam migration dosyaları oluştur
   Tek bir schema.sql yerine:

* migrations klasörü oluştur
* her tablo için ayrı migration oluştur
* create_users_table.sql
* create_pets_table.sql
* create_shelters_table.sql vb.

8. Seed sistemi oluştur
   Örnek:

* admin kullanıcı
* birkaç shelter
* birkaç pet ilanı
  otomatik eklensin.

9. Frontend ve backend tamamen dinamik çalışsın
   Şu alanlar DB’den gelsin:

* ilan sayıları
* favori sayıları
* shelter toplam pet sayısı
* adopted count
* featured listings
* dashboard istatistikleri
* detail page verileri
* homepage counters

Hardcoded hiçbir sayı kalmasın.

10. API yapısını profesyonel hale getir
    Aşağıdaki endpointler tam çalışsın:

Auth:
POST /api/auth/register
POST /api/auth/login
GET /api/auth/me

Pets:
GET /api/pets
GET /api/pets/:id
POST /api/pets
PUT /api/pets/:id
DELETE /api/pets/:id

Shelters:
GET /api/shelters
GET /api/shelters/:id

Favorites:
POST /api/favorites/:petId
DELETE /api/favorites/:petId
GET /api/favorites

11. Authentication sistemi kur

* JWT authentication
* middleware auth koruması
* bcrypt password hashing
* protected routes

12. Backend mimarisini temizle
    Controller / Route / Service mantığı kullan.
    Kodları modüler hale getir.

13. Frontend API bağlantılarını güncelle
    axios baseURL kullan.
    Environment variable destekli yapı kur:
    VITE_API_URL=http://localhost:5000/api

14. Projeyi tek komutla çalıştırılabilir hale getir
    Root package.json içinde:
    npm run dev

hem frontend hem backend birlikte çalışsın.

15. README oluştur
    Şunları anlatsın:

* PostgreSQL kurulumu
* database oluşturma
* env ayarları
* migration çalıştırma
* seed çalıştırma
* projeyi başlatma

Kodları production mantığıyla düzenle.
Temiz, ölçeklenebilir ve gerçek bir SaaS mimarisi gibi ilerle.
Mevcut UI tasarımını bozma.
Sadece gerekli frontend değişikliklerini yap.
